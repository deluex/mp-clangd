# mp_clangd M1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 mp_clangd M1：通用 ProfileSet 契约与核心（物化、include 图、状态）、内置 cdb-provider、CLI、Ascend 示例 provider（probe + 日志采集）和 VSCode 扩展。

**Architecture:** 插件层（provider）负责把每个 TU 拆出来并输出 ProfileSet；核心只消费 ProfileSet，负责 profile/unit 选择、物化 `.mpclangd/compile_commands.json`、include 图、状态与 clangd 接入。核心不含 CDB、bisheng 或 Ascend 分支。

**Tech Stack:** TypeScript 5.x、Node 24、npm workspaces、Vitest、tsup、esbuild、VSCode Extension API。依赖：`yaml`、`fast-glob`、`shell-quote`。

**Spec:** `docs/superpowers/specs/2026-11-20-mp-clangd-multiconfig-design.md`

## Global Constraints

- 代码注释与字符串使用英文；项目文档使用简体中文（CLAUDE.md 规则）。
- Node >= 24（宿主机 v24.18）；包管理用 npm workspaces。
- M1 不 fork clangd；所有 clangd 交互通过官方扩展与 `clangd.arguments`。
- 核心包不得 import `fast-glob`、`shell-quote`、`bisheng`、CDB 解析或任何 Ascend 概念。
- ProfileSet 中 `directory` 必须是绝对路径；相对 `file` 按 `directory` 解析。
- 所有写入 `.mpclangd/` 的 JSON 使用原子写（临时文件 + rename）。
- 临时文件放在项目 `.tmp/`；测试使用 `os.tmpdir()`；不得提交 `.mpclangd/`、`node_modules/`、`dist/`。
- 每个任务结束运行 `npm test`，全绿后提交。

## Review Focus

1. **相对路径**：CDB entry 的 `file` 是相对路径时，必须按 entry 的 `directory` 解析，而不是进程 cwd；错误的解析会让 clangd 找不到文件。
2. **单文件切换隔离**：给某个文件选 unit 后重新物化，其他文件仍使用各自的选择或默认第一条；错误实现会把所有文件重置。
3. **include 环与重复包含**：头文件互相 include 或同一头被多次包含时，include 图不能死循环，根路径不能重复。
4. **provider 失败**：command provider 退出码非 0、输出非 JSON 或 ProfileSet 非法时，CLI/扩展必须给出可读错误，不能让未捕获异常冒泡。
5. **header entry 替换**：为头文件物化 entry 时，必须替换 `arguments` 中的源文件 token，而不是再追加一个源文件；否则 clangd 会把它当成两个输入。

- [ ] **Step 3: 实现 entries.ts**

- `normalizeEntry` 返回 `{ ...entry, file: path.resolve(entry.directory, entry.file) }`。
- `entryKey` 用 `createHash('sha1')` 对 `directory + '\0' + arguments.join('\0')` 求 hex。
- `unitsForFile`：按 `normalizeEntry(file)` 过滤，按 `entryKey` 去重，按标签排序。
- `deriveUnitLabel`：

  2. 否则取 `-o` 下一个 token 的 `basename`，若与其他 entry 不同则使用。
  3. 否则使用 `unit ${index + 1}`（index 为该 entry 在输入顺序中的位置）。

- `sanitizeArgs`：删除匹配 `remove_args` 的 token（`*` 后缀按前缀匹配；处理 `-xasc`、`-x asc`、`-xcce`、`-x cce` 四种写法），加入 `add_args`（若不存在）。
- `buildClangdArgs`：`sanitizeArgs` 后加入 `-D${macro}=1`（`macro` 以 `__` 开头）和 `-D${keyword}=`；返回数组。
